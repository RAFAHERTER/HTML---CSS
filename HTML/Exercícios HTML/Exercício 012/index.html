Os diversos "source" embutido dentro da tag vídeo/áudio, é para referenciar o mesmo vídeo, porém de diferentes tipos de arquivos, como o mp4,mp3, webm, ogg e entre outros. Desse jeito as várias plataformas e navegadores sejam compatíveis ao seu vídeo/áudio e poder reproduzi-los.

O "poster" dentro da tag video é para colocar uma imagem para a thumb do vídeo.

Usando dessa forma, apenas um vídeo/áudio será reproduzido na sequência que foi colocado no código por ordem de compatibilidade com o site. Portanto, caso não consgiga reproduzir o primeiro vídeo/áudio, tentará reproduzir o segundo e assim por diante.

Caso não consiga reproduzir nenhum desses vídeos, o desenvolver deverá colocar a seguinte frase: Seu navegador não tem compatibilidade para reproduzir este vídeo.

CUIDADO! Ao hospedar videos dentro do site o consumo pode ser gigantesco para seu cliente, caso um monte de pessoas acesse o site mesmo utilizando um arquivo leve.

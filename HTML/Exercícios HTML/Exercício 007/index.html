Principais formatações

Negrito / Destaque

Nessa frase temos um termo em negrito usando a tag <B>, porém ela foi feita na forma sem significado, ou seja sem ser na forma semântica

Nesta frase, tenho um TERMO EM DESTAQUE na forma semântica usando a tag <STRONG>

Itálico / Ênfase

Nesta frase, temos um termo em itálico usando a tag <I> (NÃO SEMÂNTICA)

Nesta frase temos um termo em ênfase usando a tag <EM> (SEMÂNTICA)

Texto marcado

Podemos também criar um texto marcado usando a tag <MARK>

E no outro parágrafo, temos outro texto marcado no final

Texto GRANDE e pequeno

Estamos criando um texto grande(tag <big>) e um texto pequeno (tag <small>) neste parágrafo

Texto deletado

Podemos marcar um texto como excluído para indicar que ele deve ser lido, mas não considerado (tag <del>)

Texto inserido

Podemos marcar um texto como inserido para dar um ênfase para indicar que ele foi adicionado depois (semântica) (tag <ins>)

Existe também o sublinhado com a tag <U> (não semântico)

Texto subrescrito

Para inserir coisas do tipo:
x20 + 3 usa-se a tag <sup>

Texto subscrito

Para inserir coisas do tipo:
H2O usa-se a tag <sub>

Imagens dinâmica

Tente abrir esse site em vários dispositivos diferentes ou simplesmente aumente e diminua o tamanho do seu navegador

Isso é utilizado principalmente, para quando você quer acessar um site dentro de aparelhos diferentes, como Celular, tablet, ou computador. Para assim termos diferentes soluções de imagens para cada aparelho com o objetivo de suportar as imagens e evitar o scroll lateral de fotos muito grandes

Usamos a tag <picture> para podermos colocar todas as nossas funcionalidades dentro dela, inclusive a imagem BASE com a tag "img"

O source media= "min ou max", servem para delimitar até quantos píxels no maximo ou no mínimo é necessário para que a foto/imagem seja alterada

Audios

Vamos aprender a reproduzir audios em HTML5.
Da forma mais simples usamos a tag <audio + "controls" + "autoplay">.
Aceitam formatos MP3, WAV e OGG

Agora da maneira mais complexa: usamos a tag <audio> e dentro das TAGs usamos o <source src="" type=""> sendo o type, para arquivos em mp3, utilizar mpeg, para arquivos em ogg usar type ogg, e para arquivos em WAV usar type wav.

E a ordem que for colocar no código importa, pois eles tentarão rodar o seu áudio na sequência.

Além disso usa-se dentro da tag o "preload" que significa em qual momento o seu áudio irá carregar para o cliente. Se o seu site só carregar quando o áudio carregar também (auto)(perigoso caso seja um áudio muito grande e pesado). Se ele carrega gradualmente depois do site ter sido carregado (metadata)(recomendado). Ou deixar no "none" que faria que seu áudio fosse carregado apenas quando o cliente clicasse para reproduzi-lo.

Também usa dentro da tag "controls" para mostrar os controle para reproduzir os áudios.
Também usa-se o loop, (caso queira) que gera um loop quando o áudio acaba, fazendo-o recomeçar.

Lembre-se sempre, cuidado com direitos autorais com os áudios que for colocar em seu site.
Para pegar áudios sem licensas no YouTube, clique na sua conta (já dentro do YouTube), Vá em Youtube Studio, e depois no canto esquerdo vá em biblioteca de áudio. Lá terá uma infinidade de áudios que poderá utilizar.


Caso o navegador do cliente nao reproduza áudio, coloque ele como arquivo baixável para que ele possa instalá-lo.

Listas ordenadas

Usamos as listas ordenadas para indicar que a sequência das ações importam. Podemos fazer listas ordenadas com a tag <ol> e sempre que for escrever algo na lista deve estar compreendido entre as tags <li>.
Exemplo: O que eu faço depois que eu acordo

  1. Faço minhas necessidades
  2. Escovo os dentes
  3. Arrumo a minha cama
  4. Tomar café
  5. Preparar para o trabalho
Também podemos escolher que tipo de sequência será seguida pela lista, se será numérica, por letras, ou por números romanos.
Assim:

  2. Escovo os dentes
  3. Arrumo a minha cama
  4. Tomar café
  5. Preparar para o trabalho

Lista não ordenada

Podemos utilizar uma forma de lista que não depende da sequência, e sim apenas listá-las. Podemos utilizar formatos diferentes também, como DISC, CIRCLE e SQUARE
Assim temos:

  • Farinha de trigo
  • Cenoura
  • Fermento
  • Chocolate
  • Granulado
  • Manteiga
  • Whatever man

Lista dentro de listas

Podemos fazer listas dentro de listas caso queiramos aprofundar sobre um assunto em específico:
Assim: Lista de coisas que eu faço quando acordo

  1. Levantar da cama
    1. Acordar
    2. Abrir os olhos
    3. Retirar cobertor
    4. Sentar na cama
    5. Levantar da cama
  2. Ir até o banheiro
    1. Fecha a porta do banheiro
    2. Tranca a porta
    3. Escova os dentes
      • Pegar escovas de dente
      • Passar creme dental na escova
      • Esfregar escova nos dentes
    4. Enxáguo a boca
    5. Seco meu rosto
    6. Saio do banheiro
  3. Ir à cozinha
  4. Tomar café

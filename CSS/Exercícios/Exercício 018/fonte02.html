FONTES BAIXADAS

Sim as letras ficaram muito poluídas kkkkkk mas deu pra entender.

Visite o site do google fonts pela página anterior. Ou visite este site dafont.com para acessar outras fontes mais personalizadas. Certifique-se que a fonte possuí caracteres com acentuação (glifos), a maioria das vezes o seu cliente irá trazer a fonte que deseja para o site que você desenvolverá, porém tenha certeza que cumpre papel necessário.

No site "dafont" Você poderá baixar infitnitas variedades de fontes. Escolha uma delas, baixe e descompacte deixando dentro da sua pasta.

Crie um regra no seu estilo CSS "@" com o comando "font-face" que já criará um modelo para você colocar a URL da fonte baixada.

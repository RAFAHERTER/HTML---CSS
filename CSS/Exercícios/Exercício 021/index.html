Modelo de Caixas

Tudo dentro do HTML, estão dentro de caixas. Quando criamos a Tag "h1" estamos configurando a caixa do h1 que, por sua vez já possuí seu espaço determinado dentro de um site, você apenas modifica suas posições, tamanho, fontes e etc.

Todas as caixas possuem suas larguras (width) e a sua altura (height)

Temos também as bordas (linhas dos compomentes da HTML) (BORDER)

Temos também o padding, fazendo com que a nossa borda fique distante do conteúdo/texto. O padding é um espaço interno das CSS.

Temos também a margem, (margin), que é um espaço externo do conteúdo, que irá definir a distância entre o a borda com

Temos também o outline, que é o traçado por fora do elemento

Tipos de Caixas

Box Level

As box levels são mais utilizadas para espaços grandes dentro do código que quebraria a linha.
Utilizamos várias tags para estabelecer esses espaçamentos.

EXEMPLOS:

  • div
  • h1 - h6
  • p
  • main
  • header
  • article
  • aside
  • footer
  • form
  • video

Inline-level

Utilizamos o "span" para poder estabelecer espaçamentos, na maioria das vezes, dentro de textos, sem haver a quebra de linha.

EXEMPLOS:

  • span
  • a
  • code
  • small
  • strong
  • em
  • sup / sub
  • label
  • button
  • input
  • select
